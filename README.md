# 교차로 차량 카운터 대시보드

교차로 현장에서 차량 통행량을 빠르게 집계하고, 15분 단위로 저장·확인·내보낼 수 있는 모바일 친화적인 웹 대시보드입니다.

## 주요 기능

- 1~12번 전체 모드와 2·3·4·6·7·8 현장 모드
- 큰 `− / +` 버튼을 이용한 빠른 차량 집계
- 00:00부터 15분 단위 시간 구간 저장
- 저장 후 다음 시간 구간으로 자동 이동
- 저장 기록 표 확인, 복사, CSV 다운로드
- 동연사거리 엑셀 양식에 저장된 15분·번호별 기록 자동 입력 및 다운로드
- 흰색·검정색·은은한 그린 테마
- 버튼 효과음, 소리 종류 및 볼륨 설정
- 브라우저 로컬 저장소를 이용한 작성 내용 유지

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드를 확인하려면 다음 명령을 사용합니다.

```bash
npm run build
```

집계 기록과 설정은 현재 브라우저의 로컬 저장소에 보관됩니다. 다른 기기나 브라우저와 자동 동기화되지 않으므로, 필요한 기록은 CSV로 내려받아 보관하세요.
