# 교차로 차량 카운터 대시보드

교차로 현장에서 차량 통행량을 빠르게 집계하고, 15분 단위로 저장·확인·내보낼 수 있는 모바일 친화적인 웹 대시보드입니다.

## 주요 기능

- 1~12번 전체 모드와 2·3·4·6·7·8 현장 모드
- 모드 3: 3·2·1 / 4·5·6 / 12·11·10 / 7·8·9 배치의 12개 카드 클릭 모드
- 모드 3 카드 좌클릭 +1, 우클릭 −1, 좌회전·직진·우회전 음영 구분
- 모드 1·2는 카드 클릭 방식과 모바일용 −/+ 버튼 방식을 설정에서 선택
- 규호 모드: 6·5·4 / 7·8·9 / 3·2·1 / 10·11·12 배치와 승용·버스·화물 6종 분류 집계
- 규호 모드는 차량 분류를 선택한 뒤 방향 카드 좌클릭 +1, 우클릭 −1
- 모드별로 분리된 여러 개의 24시간 기록 슬롯 생성·선택
- 기록 슬롯 이름 변경 및 내보내기 파일명 자동 반영
- 확인 단계를 거치는 기록 슬롯 삭제
- 큰 `− / +` 버튼을 이용한 빠른 차량 집계
- 00:00부터 15분 단위 시간 구간 저장
- 저장 후 다음 시간 구간으로 자동 이동하며 자정을 지나도 한 기록표로 연결
- 저장 기록 표 확인, 복사, CSV 다운로드
- 동연사거리 엑셀 양식에 저장된 15분·번호별 기록 자동 입력 및 다운로드
- 엑셀 파일을 열 때 합계·보정 수식 전체 자동 재계산
- 흰색·검정색·은은한 그린 테마
- 버튼 효과음, 소리 종류 및 볼륨 설정
- 브라우저 로컬 저장소를 이용한 작성 내용 유지

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드를 확인하려면 다음 명령을 사용합니다.

```bash
npm run build
```

## Vercel 배포

Vercel에서 이 GitHub 저장소를 Import하면 Next.js 프로젝트로 자동 인식됩니다. Root Directory는 저장소 루트, Build Command는 `npm run build`를 사용합니다.

Project Settings → Environment Variables에 아래 네 값을 추가한 뒤 배포하세요.

- `DASHBOARD_NAME`: 화면에 표시할 사용자 이름
- `DASHBOARD_EMAIL`: 로그인 이메일
- `DASHBOARD_PASSWORD`: 로그인 비밀번호
- `AUTH_SECRET`: 충분히 긴 임의 문자열

값의 형식은 `.env.example`에서 확인할 수 있습니다. 비밀번호와 `AUTH_SECRET`은 GitHub에 직접 올리지 마세요. 환경변수를 변경했다면 Vercel에서 다시 배포해야 적용됩니다.

기존 Sites 배포를 확인할 때는 `npm run build:sites`를 사용할 수 있습니다.
